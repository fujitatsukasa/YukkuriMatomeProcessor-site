## 開発内容の説明案

OTM株式会社は、クリエイターと小さなチームに向け、Web・WindowsアプリケーションとAIを組み合わせたソフトウェアを開発しています。情報整理、制作の前準備、外部ツール間の手作業を一つの流れにつなぎ、人が考え、つくる時間を増やすことを目指しています。

現在の自社製品「ゆっくりまとめプロセッサー」は、素材の取得、台本案の作成支援、編集用データの整理を支援するWindows向けアプリケーションです。最終編集はYMM4で行い、出典・素材の権利・内容は利用者が確認します。

今後のAI活用では、文章・台本の作成支援、文書検索、構造化された出力を、利用者が編集・検証できる画面へ接続する構成を検討しています。Claudeを含むモデルAPIは、品質、費用、扱う情報、運用条件を比較して選びます。Claudeを本番サービスで導入済み、提携済み、採択済みとは主張しません。

### English draft

OTM Corporation develops software for individual creators and small teams. We build web and Windows applications that connect information processing, creative preparation, and external tools into practical workflows. Our goal is to give people more time to think and create by reducing repetitive preparation and manual transfers between tools.

Our current in-house product, Yukkuri Matome Processor, is a Windows application that helps creators collect materials, prepare draft scripts, and organize data before final editing in YMM4. Users remain responsible for checking sources, content, material rights, and the final edit.

We are exploring AI-assisted writing, document search, and structured outputs integrated into interfaces where users can review and edit results. We would evaluate Claude and other model APIs for quality, cost, data handling, and operational requirements. We are not claiming an existing production Claude integration or an Anthropic partnership.
